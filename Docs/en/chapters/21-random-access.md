# 21. Random Access 是什么？

## Random Access

中文：

> **随机接入**

假设 600 台设备都想跟一个 Reader 讲话。

你不可能让大家同时喊：

```text
TAG1TAG27TAG384TAG503...
```

完全听不清。

所以需要某种：

> 接入机制。

其中一种方法就是：

> 每个 device 随机选一个机会说话。

这就是 random access。
