# 25. What is an AO?

## AO = Access Occasion

You can first think of it as:

> **A location / opportunity where a device can send Msg1.**

AOs can differ in:

* time
* frequency

For example:

```text
             Frequency
             ↑
AO3       [     ]
AO4       [     ]

AO1       [     ]
AO2       [     ]
           → Time
```

Each device randomly chooses an AO.
