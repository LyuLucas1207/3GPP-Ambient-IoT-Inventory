# 63. What does periodic mean?

## Periodic

Periodic means:

> repeating on a fixed schedule.

For example:

```text
0 ms   Paging
12 ms  Paging
24 ms  Paging
36 ms  Paging
48 ms  Paging
```

that is:

> once every 12 ms.
