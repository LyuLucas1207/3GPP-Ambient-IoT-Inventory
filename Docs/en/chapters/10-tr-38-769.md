# 10. What is a TR?

## TR = Technical Report

In plain English:

> **a technical study document (not yet a frozen standard).**

3GPP publishes many technical documents.

This paper cites:

> TR 38.769

which means:

> a 3GPP Ambient IoT technical study report.

So when you see:

```text
TR [3]
```

do not panic.

It just means:

> Technical Report number 3 in the reference list.
