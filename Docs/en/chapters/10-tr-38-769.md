# 10. TR 是什么？

## TR = Technical Report

中文：

> **技术报告**

3GPP 会有很多技术文档。

这篇 paper 引用了：

> TR 38.769

也就是：

> 3GPP 的某份 Ambient IoT 技术研究报告。

因此你看到：

```text
TR [3]
```

不要怕。

就是：

> Reference 3 那份 Technical Report。
