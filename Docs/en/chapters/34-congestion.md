# 34. What is congestion?

## Congestion

A collision is one crash.

Congestion is:

> The whole system has too many people, so there are lots of crashes.

For example:

```text
600 devices
8 AOs
```

That is clearly crowded.

Like:

> 600 cars fighting over 8 very short on-ramps.
