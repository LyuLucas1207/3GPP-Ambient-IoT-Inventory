# 26. 为什么既有时间又有频率？

因为无线资源是二维的：

```text
          frequency
              ↑
              │
              │
              │
              └────────→ time
```

所以两台设备可以：

### 时间不同

```text
Tag A: now
Tag B: later
```

或者：

### 频率不同

```text
Tag A: frequency 1
Tag B: frequency 2
```

都能避免互相撞。
