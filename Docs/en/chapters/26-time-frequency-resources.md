# 26. Why both time and frequency?

Because wireless resources are two-dimensional:

```text
          frequency
              ↑
              │
              │
              │
              └────────→ time
```

So two devices can:

### Differ in time

```text
Tag A: now
Tag B: later
```

or:

### Differ in frequency

```text
Tag A: frequency 1
Tag B: frequency 2
```

Either way they can avoid colliding with each other.
