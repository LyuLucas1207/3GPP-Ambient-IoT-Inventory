# 47. What is the ON state?

## ON state

Meaning:

> The device is on and can communicate.

It can:

* receive paging
* transmit Msg1
* receive Msg2
* transmit Msg3

But:

> It consumes energy.

The paper defines the ON state as a state that can be used for reception/transmission.
