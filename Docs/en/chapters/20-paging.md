# 20. Paging 是什么？

这是你之后 simulation 必须非常熟悉的词。

## Paging

你可以理解成：

> **Reader 喊设备：“醒醒！现在轮到你们跟我通信了！”**

例如：

```text
Reader:

"HELLO ALL TAGS, INVENTORY STARTING!"
```

这条唤醒/触发消息就是：

> A-IoT paging

论文定义得很明确：

> A-IoT paging 是一个 R2D message，用来触发 random access procedure。
