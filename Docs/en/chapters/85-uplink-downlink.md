# 85. What are uplink / downlink?

## Downlink

```text
BS → device
```

Coming down from the base station.

---

## Uplink

```text
device → BS
```

Going up from the user device.

In this paper they are close to:

* R2D
* D2R

but they are not exactly the same in every situation.
