# 9. Release 18 / Release 19 是什么？

3GPP 的标准不是一次写完。

它一代一代发布。

比如：

## Release 18

简称：

> Rel-18

是某一个版本阶段。

然后：

## Release 19

简称：

> Rel-19

继续加入新的功能。

这篇论文说：

* Release 18 做 A-IoT feasibility study
* Release 19 进一步研究具体 solutions
