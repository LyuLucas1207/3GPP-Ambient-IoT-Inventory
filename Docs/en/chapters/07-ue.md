# 7. UE 是什么？

## UE = User Equipment

中文：

> **用户设备**

比如：

* 手机
* 平板
* 某些 5G terminal

在 3GPP 语言里，你的手机不是通常叫 phone，而经常叫：

> UE

所以论文说：

> BS 和 UE 都可能充当 A-IoT reader。
