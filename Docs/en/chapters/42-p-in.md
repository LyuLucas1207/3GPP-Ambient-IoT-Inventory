# 42. \(p_{in}\) 是什么？

## in = input / incident

$$
p_{in}
$$

就是：

> **真正到达 tag 的 RF power。**

Reader 虽然发：

> 很强的 signal

但是信号在空气里传播会衰减。

所以：

```text
离 Reader 很近
→ pin 较高

离 Reader 很远
→ pin 较低
```
