# 53. Monitoring 是什么意思？

## Monitoring

这里就是：

> **设备保持 receiver 打开，等 Reader 的 paging。**

不是说：

> 它正在持续传数据。

而是：

> 耗着电、睁着耳朵听。

这恰恰很耗能。
