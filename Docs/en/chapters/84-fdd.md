# 84. FDD 是什么？

## FDD = Frequency Division Duplex

通信双方两个方向用不同 frequency。

比如：

```text
frequency A:
BS → UE

frequency B:
UE → BS
```

叫：

> uplink/downlink 分频。

论文介绍 A-IoT spectrum 时提到 FDD spectrum。

同样：

> 不是你第一阶段 simulation 的核心。
