# 82. BPSK 是什么？

## BPSK = Binary Phase Shift Keying

也是 modulation。

不同之处：

> 不用“有波 / 没波”，而是用两个相位表示 0 和 1。

例如：

$$
0^\circ\rightarrow0
$$

$$
180^\circ\rightarrow1
$$

你现在知道名字就够了。

Figure 5(b) reproduction 不需要你先成为 BPSK 专家。
