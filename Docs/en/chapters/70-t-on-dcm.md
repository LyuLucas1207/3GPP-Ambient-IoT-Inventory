# 70. What is \(T_{\mathrm{on}}^{\mathrm{DCM}}\)?

It is:

> how long the device stays ON inside each paging period.

The paper requires:

$$
T_{\mathrm{sl}}^{\mathrm{DCM}}+T_{\mathrm{on}}^{\mathrm{DCM}}=T_{pg}
$$

that is:

```text
one paging period
=
sleep duration
+
on duration
```
