# 57. P3：一直撞车，重试，把电耗光

假设设备有电。

但是：

```text
Attempt 1 → collision
Attempt 2 → collision
Attempt 3 → collision
Attempt 4 → collision
```

它每一次都需要：

* 醒来
* receive
* transmit
* wait

于是一直耗电。

最后：

```text
没成功
+
没电了
```

这就是 P3。
