# 58. 于是论文提出 DCM

## DCM = Duty Cycled Monitoring

这个名字很重要。

### Duty Cycle

意思：

> 一个设备不是一直 ON，而是周期性 ON / OFF。

比如：

```text
ON   OFF OFF OFF   ON   OFF OFF OFF   ON
```

而不是：

```text
ON ON ON ON ON ON ON ON ON
```

所以：

## Duty Cycled Monitoring

就是：

> **间歇式监听。**
