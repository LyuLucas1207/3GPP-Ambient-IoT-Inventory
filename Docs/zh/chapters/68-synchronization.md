# 68. Synchronization 是什么？

## Synchronization = 同步

就是：

> 两边时间对齐。

Reader 知道：

```text
Paging at t=12,24,36...
```

Tag 也知道。

所以 Tag 可以：

> 只在 paging 快来时醒。

这是非常经典的通信思想。
