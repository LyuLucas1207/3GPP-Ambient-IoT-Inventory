# 1. IoT 是什么？

## IoT = Internet of Things

中文通常翻译：

> **物联网**

普通 Internet 是：

```text
电脑
手机
服务器
```

互相联网。

IoT 则是：

```text
温度传感器
智能门锁
货物标签
摄像头
工业机器人
智能电表
汽车
```

这些“东西”也联网。

所以：

$$
IoT = Internet\ of\ Things
$$

就是：

> **让大量现实世界里的设备能够通信。**
