# 25. AO 是什么？

## AO = Access Occasion

中文你可以先理解：

> **一次可以发送 Msg1 的位置 / 机会。**

AO 可以在：

* 时间上不同
* 频率上不同

例如：

```text
             Frequency
             ↑
AO3       [     ]
AO4       [     ]

AO1       [     ]
AO2       [     ]
           → Time
```

每个 device 随机选择一个 AO。
