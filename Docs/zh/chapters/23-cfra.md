# 23. CFRA 是什么？

## CFRA = Contention-Free Random Access

就是：

> **无竞争随机接入**

Reader 可以事先安排：

```text
Tag A → 位置 1
Tag B → 位置 2
Tag C → 位置 3
```

因此不会撞。

但问题是 inventory 刚开始的时候：

> Reader 甚至不知道附近有哪些设备。

所以论文说：

> 对未知数量设备的 inventory，通常使用 CBRA。
