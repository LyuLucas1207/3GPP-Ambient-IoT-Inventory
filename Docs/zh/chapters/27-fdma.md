# 27. FDMA 是什么？

## FDMA = Frequency-Domain Multiple Access

中文：

> **频分多址**

就是：

> 不同设备用不同频率同时通信。

比如：

```text
frequency 1 → Tag A
frequency 2 → Tag B
frequency 3 → Tag C
```

论文提到 A-IoT 可以利用 frequency-domain multiple access。
