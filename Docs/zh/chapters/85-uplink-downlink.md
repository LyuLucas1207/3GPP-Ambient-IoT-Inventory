# 85. Uplink / Downlink 是什么？

## Downlink

```text
BS → device
```

从基站下来。

---

## Uplink

```text
device → BS
```

从用户设备上传。

在本论文里和：

* R2D
* D2R

概念相近，但不是任何情况下完全等价。
