# 6. BS 是什么？

## BS = Base Station

中文：

> **基站**

你平时手机连接 4G/5G：

```text
手机 ←→ 基站
```

那个基站就是 BS。

在论文的 factory simulation 里面：

> 工厂里有 18 个 base stations，一次选一个进行 inventory。

正式论文设定是一个 \(120m\times60m\) 的室内工厂，18 个 BS 中一次一个负责 inventory，发射功率 33 dBm。
