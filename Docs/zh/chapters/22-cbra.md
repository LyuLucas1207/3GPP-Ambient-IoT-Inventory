# 22. CBRA 是什么？

## CBRA = Contention-Based Random Access

拆开：

### Contention

竞争。

### Based

基于。

### Random Access

随机接入。

所以：

> **基于竞争的随机接入。**

意思是：

设备之间没有提前分配独占资源。

大家自己随机选。

所以可能：

> 撞车。
