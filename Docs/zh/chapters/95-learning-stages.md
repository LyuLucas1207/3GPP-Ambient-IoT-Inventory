# 95. 所以你现在不要焦虑“我什么都不会”

你现在更适合把整个任务看成：

```text
阶段 1
学会语言

阶段 2
看懂系统

阶段 3
看懂公式

阶段 4
把系统画成 state machine

阶段 5
把 state machine 写成 simulation

阶段 6
复现 Figure 5(b)

阶段 7
解释为什么结果这样
```

**不要直接跳阶段 5。**

如果你现在直接让我给你代码，我反而认为不是最好的做法。

因为教授如果之后问你：

> Why did you model it this way?

你很容易答不上来。
