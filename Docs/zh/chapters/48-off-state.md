# 48. OFF state 是什么？

## OFF state

意思：

> 主电路关闭。

设备：

* 不能 receive
* 不能 transmit
* 可以 harvest energy

所以：

```text
OFF
→ 充电

ON
→ 工作 / 耗电
```
