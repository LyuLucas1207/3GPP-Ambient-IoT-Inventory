# 17. 那 Ambient IoT 和 RFID 是不是一个东西？

不是完全一样。

但是你作为新人可以先这样理解：

> **A-IoT Device 1 ≈ 更加 3GPP / cellular 化的高级 RFID-like device**

传统 RFID 和 3GPP Ambient IoT：

共同点：

* ultra-low-power
* tag
* reader
* backscatter
* inventory

区别在于：

Ambient IoT 希望进入：

> 3GPP / cellular ecosystem

和：

* 5G NR
* BS
* UE
* licensed spectrum
* standardized cellular procedures

结合。
