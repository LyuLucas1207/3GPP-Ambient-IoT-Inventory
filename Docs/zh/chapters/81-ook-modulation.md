# 81. OOK 是什么？

## OOK = On-Off Keying

这是一种非常简单的 modulation。

---

## Modulation 是什么？

### Modulation = 调制

意思：

> 怎样把 0 和 1 放到无线波上。

---

OOK 特别简单：

```text
carrier ON  → 1
carrier OFF → 0
```

所以：

```text
1 0 1 1 0

ON OFF ON ON OFF
```

这非常适合低复杂度设备。

论文说 R2D 使用 OOK。
