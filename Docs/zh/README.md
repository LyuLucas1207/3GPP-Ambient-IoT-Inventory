## 结构约定

- **一个 chapter = 一个 `.md` 文件**
- **文件夹只用来分组**（例如 `chapters/`、`figures/`），不是“每章一个文件夹”
- 章节编号与讲义 **0–97** 对齐（另有 Preface）

```text
Docs/
├── README.md
├── content.md                 ← 总目录（点击跳转）
├── story.md                   ← 真实世界故事（快速直觉）
├── chapters/
│   ├── 00-research-fit.md
│   ├── 00-warehouse-story.md
│   ├── 01-iot.md
│   └── ... 97-stage1-checkpoint.md
├── figures/
│   ├── README.md
│   ├── figure-01-cbra.md
│   └── ...
└── ambient_iot_beginner_guide.md  ← 拆分前/单文件备份
```

每章文件内都有：返回目录 / 上一章 / 下一章。
