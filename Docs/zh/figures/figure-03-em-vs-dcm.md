# Figure 3：EM vs DCM

这是整篇论文最关键的直觉图之一。

## EM

```text
充满 → 一直听 → 听到很低 → OFF → 大缺口要补很久
```

## DCM

```text
充满 → 只听一小段 → 主动睡 → 小缺口很快补回来
```

## 反直觉点

“更早睡觉”不是偷懒，而是：

> **缩短 recharge time，提高下一次能参加 inventory 的概率。**

对应公式直觉：

\[
T_{recharge}=\frac{\Delta E}{P_{eh}}
\]

\(\Delta E\) 越小，恢复越快。

## 过关标准

能用一句话对比：

> EM 把杯子喝到半空再慢慢装满；DCM 只喝一小口就去接水，杯子始终比较满。
